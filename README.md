Entry for the [make.fun bounty "One Letter: Coffee or Tea"](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).

**A — coffee, one letter.**

`main.ts` writes exactly one letter, `A`, to `/output/entry.txt` — coffee.
It reads the output directory from `MAKEFUN_OUTPUT_DIR` (default `/output`),
creates it if needed, and validates the letter is a single A–Z character
before writing. No network, no secrets, no files outside the repo.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/coffee-test-out node main.ts
```
